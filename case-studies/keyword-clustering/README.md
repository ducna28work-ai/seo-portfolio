# Keyword Clustering & Search Intent Case Study 🔎

A practical keyword clustering project for a travel website serving Inbound and Domestic tourism markets.

The project focused on organizing search queries by topic, search intent, and page purpose, then mapping keyword groups to an appropriate website structure.

> **Confidentiality Note:** Specific keyword volumes, business-sensitive information, customer data, and internal company information have been omitted to protect confidentiality.

## 🎯 Project Objective

The objective was to organize travel-related search queries into meaningful keyword groups based on:

- Search intent
- Topic relevance
- Search behavior
- User journey
- Page purpose
- Content relationships

The final goal was to determine which keywords could be targeted by the same page and which required separate pages.

---

## ⚠️ Keyword Research Challenges

Travel-related search behavior can be highly fragmented.

Users may search for the same destination using different combinations of:

- Destination
- Tour type
- Travel duration
- Activities
- Season
- Price
- Transportation
- Travel requirements
- Accommodation
- Travel planning questions

Without proper clustering, this can lead to:

- Unnecessary pages
- Keyword cannibalization
- Weak page targeting
- Duplicate or overlapping content
- Poor content architecture
- Difficult internal linking

---

## 🎯 Search Intent Classification

Keywords were classified according to the underlying purpose of the search.

Typical intent categories included:

### Informational

Users looking for information, guides, or answers.

### Commercial Investigation

Users comparing destinations, tours, services, or travel options.

### Transactional

Users showing stronger intent to book, inquire, or purchase a travel product or service.

### Navigational

Users looking for a specific destination, brand, website, or service.

Search intent was used as one of the main signals when deciding whether keywords should be grouped together or separated into different pages.

## 🔎 SERP Validation

Keyword similarity alone was not considered sufficient for clustering.

Search results were reviewed to determine whether different queries showed similar page types and search intent.

The analysis considered:

- Ranking page types
- Search intent
- Destination relevance
- Tour/product relevance
- Content format
- Similarity between search results

If two keyword groups showed significantly different search intent or SERP patterns, they could be separated into different page targets.

## 🚫 Keyword Cannibalization Prevention

Keyword clustering was also used to identify potential overlap between existing or planned pages.

Potential cannibalization risks were reviewed when:

- Multiple pages targeted the same search intent
- Similar keywords were assigned to different pages
- Two pages covered substantially similar topics
- Existing pages competed for the same search theme

The preferred approach was to clarify page purpose before creating additional content.

Depending on the situation, the solution could involve:

- Consolidating overlapping content
- Differentiating search intent
- Redefining page targeting
- Adjusting content focus
- Improving internal linking relationships

## 💡 Key Learnings

### 1. Keywords Should Be Grouped by Search Intent

Semantic similarity alone does not always mean that keywords should target the same page.

### 2. SERP Analysis Helps Validate Clusters

Search results provide useful evidence when deciding whether different queries can be served by the same page.

### 3. Keyword Mapping Should Happen Before Content Production

Assigning keywords to page purposes first can reduce unnecessary content overlap.

### 4. Clustering Is Connected to Website Architecture

Keyword research becomes more useful when the output directly informs page structure, content planning, and internal linking.
