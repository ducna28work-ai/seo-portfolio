# Keyword Research 🔍

A practical framework for keyword research and search intent analysis used in SEO projects.

The objective is to identify relevant search opportunities, understand user intent, organize keywords into meaningful groups, and map them to the appropriate pages.

---

## 🎯 Objective

Keyword research is not only about finding keywords with high search volume.

A useful keyword research process should answer:

- What are users searching for?
- Why are they searching?
- What type of content do they expect?
- Which keywords belong to the same topic?
- Which keywords should target the same page?
- Which keywords require separate pages?
- Which keywords have meaningful business value?
