# Keyword Research 🔍

A practical framework for keyword research and search intent analysis used in SEO projects.

The objective is to identify relevant search opportunities, understand user intent, organize keywords into meaningful groups, and map them to the appropriate pages.

---

## 🎯 Objective

Keyword research is not only about finding keywords with high search volume.

A useful keyword research process should answer:

- What are users searching for?
- Why are they searching?
- What type of content do they expect?
- Which keywords belong to the same topic?
- Which keywords should target the same page?
- Which keywords require separate pages?
- Which keywords have meaningful business value?

## 1. Business & Audience Research

Before collecting keywords, understand the business and target audience.

Review:

- Products and services
- Target customers
- Geographic markets
- Customer journey
- Business priorities
- Existing website structure
- Main conversion actions

This provides context for evaluating keyword relevance beyond search volume.

---

## 2. Seed Keyword Research

Start with broad topics related to the business.

Common seed sources include:

- Products
- Services
- Destinations
- Categories
- Customer problems
- User questions
- Existing website pages
- Search Console queries

Seed keywords are starting points for discovering broader search opportunities.

---

## 3. Keyword Expansion

Expand seed keywords into more specific search queries.

Useful dimensions may include:

- Topic
- Location
- Product or service
- Audience
- Price
- Duration
- Season
- Activities
- Questions
- Modifiers
- Long-tail variations

The goal is to capture different ways users express related search needs.

---

## 4. Search Intent Analysis

Classify keywords according to the user's underlying search purpose.

### Informational

Users are looking for information, answers, guides, or explanations.

### Commercial Investigation

Users are comparing options, destinations, products, or services before making a decision.

### Transactional

Users show stronger intent to purchase, book, contact, or take another commercial action.

### Navigational

Users are looking for a specific website, brand, destination, or service.

Search intent should influence both keyword prioritization and page targeting.

---

## 5. Keyword Classification

Keywords can be classified using multiple dimensions.

| Dimension | Examples |
|---|---|
| Topic | Destination, tour, activity, travel guide |
| Intent | Informational, Commercial, Transactional, Navigational |
| Funnel Stage | Awareness, Consideration, Conversion |
| Page Type | Guide, Destination, Product, Service |
| Priority | High, Medium, Low |

Classification makes large keyword datasets easier to analyze and organize.

---

## 6. Keyword Clustering

Related keywords should be grouped based on a combination of:

- Search intent
- Topic relevance
- Semantic relationship
- SERP similarity
- Page purpose

The objective is to determine which keywords can realistically be served by the same page.

A simplified structure:

**Main Topic**

↓

**Core Keywords**

↓

**Related Keywords**

↓

**Long-tail Queries**

↓

**Supporting Questions**

Detailed practical clustering and SERP validation are documented separately in the [Keyword Clustering Case Study](../../case-studies/keyword-clustering/).

---

## 7. SERP Validation

Keyword similarity alone should not determine whether keywords belong to the same cluster.

Review search results to evaluate:

- Ranking page types
- Search intent
- Content format
- Topic relevance
- Similarity between ranking pages

If search results indicate significantly different intent or page requirements, keywords may need to be separated into different targets.

---

## 8. Keyword-to-Page Mapping

After clustering, map keyword groups to appropriate pages.

A practical mapping can include:

| Keyword Group | Search Intent | Page Type | Target Page |
|---|---|---|---|
| Core topic | Primary intent | Primary page | Existing / New URL |
| Supporting topic | Secondary intent | Supporting content | Existing / New URL |
| Long-tail query | Specific intent | Article / Guide | Existing / New URL |

The mapping should define the primary purpose of each page and reduce unnecessary overlap.

---

## 9. Keyword Cannibalization Review

Review existing pages before creating new targets.

Potential cannibalization risks include:

- Multiple pages targeting the same intent
- Similar keyword groups assigned to different pages
- Pages covering substantially similar topics
- Existing pages competing for the same search theme

Possible actions include:

- Consolidating overlapping pages
- Differentiating search intent
- Redefining page targeting
- Adjusting content focus
- Improving internal linking

---

## 10. Keyword Prioritization

Not every keyword opportunity should be treated equally.

Prioritization can consider:

- Business relevance
- Search intent
- Existing ranking potential
- Search demand
- Competition
- Conversion potential
- Content effort
- Existing page availability

A practical priority model should balance **SEO opportunity with business value and implementation effort**.

---

## 11. Content Planning

Keyword research should ultimately inform content and page strategy.

The output can be translated into:

- New page opportunities
- Existing page optimization
- Content briefs
- Topic clusters
- Landing pages
- Supporting articles
- Internal linking opportunities

Keyword research is therefore an input into broader SEO planning rather than a standalone spreadsheet exercise.

---

## 12. Performance Monitoring

Keyword research should be revisited after implementation.

Monitor signals such as:

- Organic clicks
- Impressions
- CTR
- Average position
- Search queries
- Page-level performance
- New search opportunities

Search performance can reveal new queries, changing intent, and opportunities for further optimization.

---

## 🧠 Key Principles

1. **Search intent comes before search volume.**
2. **Keywords should support page purpose, not dictate it alone.**
3. **SERP behavior is useful for validating keyword relationships.**
4. **Keyword mapping should happen before large-scale content production.**
5. **Existing pages should be reviewed before creating new pages.**
6. **Keyword research should connect SEO opportunities with business priorities.**
