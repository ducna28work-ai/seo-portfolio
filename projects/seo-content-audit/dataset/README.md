# SEO Content Audit — Dataset

A synthetic dataset designed to demonstrate structured SEO content auditing across multiple URLs.

## Purpose

The dataset represents a simplified audit of website pages across different page types and search intents.

It is designed to demonstrate how an SEO audit can record:

- Search intent
- Content status
- Content issues
- On-page issues
- Internal linking opportunities
- Content overlap
- Priority
- Recommended actions

All records are synthetic and created for portfolio demonstration purposes.

## Dataset Schema

| Field | Description |
|---|---|
| `audit_id` | Unique audit record identifier |
| `url` | Audited page URL |
| `page_type` | Type of website page |
| `primary_topic` | Main topic covered |
| `search_intent` | Intended search intent |
| `content_status` | Overall content assessment |
| `main_issue` | Primary identified issue |
| `issue_type` | Issue classification |
| `priority` | Recommended implementation priority |
| `recommendation` | Proposed SEO action |
| `qa_status` | Audit QA status |

## Issue Types

The dataset uses the following issue categories:

- Intent Mismatch
- Thin Content
- Outdated Content
- Content Gap
- Structure Issue
- On-Page Issue
- Internal Linking
- Content Overlap

## Priority Levels

### High

Issues that may materially affect search intent alignment, important landing pages, usability, or content overlap.

### Medium

Issues that can improve relevance, structure, internal linking, or content depth but are less urgent.

### Low

Incremental improvements that can be addressed after higher-priority issues.

## Data Principles

The dataset is designed to demonstrate:

- Consistent issue classification
- Evidence-based recommendations
- Search-intent alignment
- Actionable prioritization
- Clear audit documentation

## Limitations

This is a synthetic SEO audit dataset.

It does not represent real client performance data, private analytics, or confidential website information.
