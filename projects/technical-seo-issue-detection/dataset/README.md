# Technical SEO Issue Detection — Dataset

Synthetic dataset demonstrating how technical SEO issues can be recorded and classified.

## Dataset Schema

| Field | Description |
|---|---|
| `issue_id` | Unique issue identifier |
| `url` | Affected URL |
| `issue_type` | Technical issue category |
| `http_status` | Observed HTTP status |
| `severity` | Issue severity |
| `issue` | Identified problem |
| `evidence` | Observable technical signal |
| `recommendation` | Recommended action |
| `qa_status` | Review status |

## Issue Types

- Crawlability
- Indexability
- HTTP Status
- Canonical
- Redirect
- Metadata
- Internal Linking

## Severity Levels

- High
- Medium
- Low

## Data Principles

Each record should contain:

- A specific affected URL
- A clearly identified technical signal
- A consistent issue classification
- A justified severity
- An actionable recommendation

## Limitations

All records are synthetic and intended only to demonstrate technical SEO analysis methodology.
