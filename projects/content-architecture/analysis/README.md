# Content Architecture — Analysis

This directory documents the analysis of the synthetic content architecture dataset.

## Analysis Objective

The objective is to demonstrate how a collection of related SEO topics can be organized into a logical website structure.

The analysis focuses on:

- Topic hierarchy
- Page roles
- Search intent
- Parent-child relationships
- Internal linking
- Potential topic overlap

## Architecture Overview

The synthetic architecture is organized around a broad:

**Vietnam Travel**

pillar.

The pillar is supported by several topic clusters:

- Vietnam Itineraries
- Vietnam Destinations
- Vietnam Tours
- Vietnam Travel Costs
- Vietnam Visa

Each cluster contains narrower supporting pages.

## Page Role Distribution

The dataset demonstrates three page roles:

### Pillar

The broadest topic and main content hub.

Example:

`Vietnam Travel`

### Cluster

Important subtopics that organize related supporting pages.

Examples:

- Vietnam Itineraries
- Vietnam Destinations
- Vietnam Tours
- Vietnam Travel Costs
- Vietnam Visa

### Supporting

Specific topics that address narrower search needs.

Examples:

- Vietnam 10 Day Itinerary
- Hanoi Travel Guide
- Vietnam Luxury Tours
- Vietnam Trip Cost by Category
- Vietnam Visa Requirements

## Search Intent Analysis

The architecture uses different search intents:

| Intent | Example |
|---|---|
| Informational | Vietnam Travel Guide |
| Informational | Hanoi Travel Guide |
| Informational | Vietnam 10 Day Itinerary |
| Commercial Investigation | Vietnam Tours |
| Transactional | Vietnam Luxury Tours |
| Transactional | Vietnam Family Tours |

This prevents the architecture from treating every related keyword as the same type of page.
