# Keyword Cannibalization Analysis — Analysis

## Analysis Objective

The objective is to demonstrate how potential keyword cannibalization can be evaluated by comparing URL topics, search intent, content purpose, and user needs.

## Analysis Workflow

**URL Pairing → Topic Comparison → Search Intent Comparison → Content Overlap → Relationship Classification → Action Recommendation → QA**

## Relationship Analysis

The synthetic dataset uses four relationship categories:

### Distinct

The pages have clearly different purposes and search intents.

Example:

- Ha Long Bay Tour
- Ha Long Bay Travel Guide

### Related

The pages cover related topics but have different levels of specificity or user needs.

Example:

- Vietnam Itineraries
- Vietnam 10 Day Itinerary

### Potential Overlap

The pages may compete for similar search intent but can potentially remain separate if their purposes are clearly differentiated.

Example:

- Vietnam Luxury Tours
- Vietnam Private Tours

### Strong Overlap

The pages serve substantially similar purposes and search intent.

Example:

- Vietnam Family Tours
- Vietnam Tours for Families

## Recommended Actions

The dataset demonstrates five possible actions:

| Action | When to Use |
|---|---|
| Keep Separate | Pages serve clearly different needs |
| Differentiate | Pages are related but can have clearer boundaries |
| Consolidate | Pages provide substantially similar value |
| Redirect | One URL should be retired in favor of another |
| Reposition | A page can target a different search intent |
